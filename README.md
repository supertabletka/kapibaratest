# Витрина «Капибара» — Telegram Mini App

Показывает наличие и цены, считает сумму («Мой расчёт»), даёт отметить позиции, за которыми человек следит, и связаться с продавцом. Заказы не принимаются, фото товаров и акций нет. Всё работает без сервера: это набор статических файлов.

## Что внутри

| Файл | Зачем |
|---|---|
| `index.html`, `style.css`, `app.js`, `logic.js` | сама витрина, трогать не нужно |
| `config.js` | название, адрес, часы, контакт продавца, ответы на быстрые вопросы |
| `data/products.json` | список товаров (или Google Таблица, см. ниже) |
| `logo.png` | необязательно: положите логотип рядом с `index.html`, он появится сам |

## Как менять товары

Откройте `data/products.json`. Каждая запись — линейка (бренд), внутри неё вкусы. Поля линейки:

- `name` — название, `sub` — подпись («Табак для кальяна · средняя крепость»)
- `desc` — короткое нейтральное описание (без рекламных слов)
- `category` — `liquid` (жидкости), `hookah` (кальян), `part` (расходники), `device` (устройства)
- `price` — число в рублях или `null`, если цена не указана
- `new` — `true`, если линейка в разделе «Новое»
- `flavors` — список вкусов: `{ "n": "Название", "s": "in" }`, где `s` — `in` (в наличии), `low` (мало), `out` (нет)

Статус линейки на карточке считается сам: «в наличии», если есть хоть один вкус. Позиция без вкусов (например, устройство) пишется по-старому: вместо `flavors` поле `status`.

### Через Google Таблицу (удобнее владельцу)

Первая строка таблицы: `id,name,sub,category,price,status,new,desc,flavors`. В колонке `flavors` вкусы пишутся через `|`, статус после двоеточия: `Груша:в наличии|Ананас:мало|Арбуз:нет`. Если статус не написан, вкус считается «нет». Затем: Файл → Поделиться → Опубликовать в интернете → формат CSV. Вставьте ссылку в `SHEET_CSV_URL` в `config.js`. Если таблица недоступна, витрина берёт `data/products.json`.

## Как запустить в Telegram

1. Выложите папку на бесплатный статичный хостинг (Cloudflare Pages, GitHub Pages или Netlify; нужен только email). Получите адрес вида `https://что-то.pages.dev`.
2. В Telegram откройте @BotFather: `/newbot`, затем `/mybots` → ваш бот → Bot Settings → Menu Button → укажите этот адрес.
3. Откройте бота и нажмите кнопку меню.

Токены и секреты в эти файлы класть не нужно, и они не требуются.

## Важно

- **Telegram в России заблокирован** с апреля 2026 года, без VPN или прокси открывается не у всех. Узнайте у владельца, как покупатели читают его канал.
- **Юридическая часть.** Реклама и дистанционная продажа никотинсодержащей продукции в РФ ограничены. Витрина сделана как справочник наличия: без фото, акций, рассылок и приёма заказов. Не добавляйте это без письменного заключения юриста именно для такой витрины.
- Слежение за наличием и расчёт хранятся только в телефоне человека. Никаких сообщений пользователям витрина не отправляет.
